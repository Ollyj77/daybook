# Daybook

OJ's calendar and rolling to-do list, as an installable web app.

- Live at https://ollyj77.github.io/daybook/
- No personal data lives in this repository. Tasks and events are read from and written to the private repo `Ollyj77/daybook-data` (`items.json`) through the GitHub API, using an access key stored only on each device.
- Plain HTML/CSS/JS in `index.html`; no build step. Push to `main` and GitHub Pages republishes in about a minute.
